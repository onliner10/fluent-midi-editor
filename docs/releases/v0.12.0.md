MPE editing, as in Ableton's Note Expression view, and an Ableton-style Preview.

- **MPE** (E, or the MPE button): each note's pitch bend is drawn on the note, one row
  per semitone; Slide (CC74) and Pressure are tabs in the lane next to Velocity.
  - Drag a line to add a point and move it; drag a point to move it. Shift moves in one
    direction, Alt snaps pitch to semitones. The value shows next to the point.
  - Click a point to select it: arrows nudge it (whole semitones, Shift for fine steps),
    Delete or a double-click removes it.
  - Ctrl + drag moves the whole envelope of every selected note; B + drag draws freehand,
    for example a vibrato. Simplify turns a dense recording into a few smooth points.
  - Recordings from MPE controllers show as smooth lines; a held value and a jump stay a
    step. Untouched notes are written back byte for byte.
  - **Convert to MPE** gives every sounding note of a plain part its own channel (2-16);
    the part's own bend, pressure and CCs move to the master channel. Set the instrument
    to MPE mode afterwards.
  - Note gestures keep working on a selected note: its edges resize it, and on a flat
    pitch line Alt + drag sets velocity and Ctrl + drag copies it.
- **Preview** (the headphones above the keys): selecting, adding or moving notes plays them,
  each for its drawn length; a clicked key rings while held, and a selection rings as a chord.
- Ctrl+D and paste replace notes a shortening hid where the copy lands.
- Drawing with a zoomed-out grid adds one note per drawn cell, so a long stroke cannot
  hang REAPER.
- Fixes for phrase length edge cases, stacked notes of one pitch and looped first passes.
